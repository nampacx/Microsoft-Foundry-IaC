# Form Recognizer (Azure AI Document Intelligence)

This Terraform file creates a single Azure AI Document Intelligence (formerly Form Recognizer) account and a resource group in Sweden Central. The account is configured with a system-assigned managed identity and basic tags.

Form Recognizer is a cognitive service that extracts structured data from documents such as invoices, receipts, and forms. It uses prebuilt and custom models to turn documents into fields you can use in downstream workflows.
